## 3. 문제 데이터 형식 (종류·출처·연도 기록)

```json
{ "subject": 1, "num": 11, "question": "...", "options": ["...","...","...","..."], "answer": 2,
  "explanation": "...", "concept": "...",
  "kind": "기출복원", "year": 2025, "round": 1, "source": "자료 이름 또는 주소(이용 허락 조건 포함)" }
```
- `kind`: `기출`(공식 기출) / `기출복원`(수험생 복원) / `자체 제작 예상문제`
- `기출`, `기출복원`은 `year`(연도)와 `source`(출처)가 없으면 추가되지 않습니다. `round`(회차)는 선택입니다.

## 4. 필요한 자료

1. **이용이 허락된 2023~2026년 필기 기출복원문제** (문제·보기·정답·해설). 직접 정리하신 것, 이용 허락을 받은 것, 라이선스(공공누리·CC 등)가 명시된 것 중 하나여야 합니다.
2. 2022년 이전 문제를 쓰려면 **2027~2030 출제기준에 포함되는지** 판단할 근거(위 출제기준)와 함께, 같은 방식으로 이용이 허락된 자료.
3. 교재의 문제를 쓰려면 출판사의 허락이 필요합니다. 개인 학습용으로 본인 기기에만 넣어 쓰는 방법은 있지만, 공개 배포(GitHub·Vercel)에는 포함하지 마세요.

## 5. 내장 자체 제작 예상문제 (300개)
- 큐넷 출제기준의 과목별 범위를 바탕으로 새로 작성한 문제입니다(기출·교재 문장 미사용). 작성 후 별도 검토자가 전 문항의 정답·해설을 재검토했고, 지적 6건(모호·표현 4, 해설 2)을 수정했습니다.
- 세부 출제기준 항목과 1:1 대조는 하지 않았습니다.
- 실제 기출·교재 문제는 저장소에 두지 않고 설정 화면 업로드(IndexedDB)로만 사용합니다.
